WAZ DAT!? — WEBSITE PROTOTYPE
=================================
Files: index.html, styles.css, script.js, thanks.html, assets/.

PREVIEW
Open index.html in a web browser. Internet access is needed to load the optional Google fonts; fallback fonts are included.

PUBLISH (EASIEST: NETLIFY)
1. Create a Netlify account and open Add new project > Deploy manually.
2. Drag the entire wazdat-website folder into the deploy area.
3. Open Netlify Forms, enable form detection if needed, and redeploy. After deployment, submit a test inquiry and verify that submissions appear in the Forms dashboard.
4. Configure email notifications for the form in Netlify settings. No customer email address is hard-coded in the site.
5. Point WazDatMedia.com DNS to the deployment using Netlify's current instructions. Enable HTTPS.
6. Before promoting the site, test contact submissions, link targets, mobile layout, QR destination, and domain/HTTPS.

IMPORTANT
The current brand lettering is custom styled HTML, NOT the original approved 3D logo art. Replace it with your actual logo asset when available.
The QR code targets https://wazdatmedia.com/; it cannot display the site until the domain routes to this website.
The contact form is set up for NETLIFY FORMS only; it does not send messages from a local file or on arbitrary hosting.
No analytics, tracking pixels, payment processing, or social media links have been added.
The $250 offer is creative deliverables only, with scope and exclusions noted on the page.
This is a launch-ready PROTOTYPE; publishing/hosting and testing still need to happen.
